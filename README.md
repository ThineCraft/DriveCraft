# DriveCraft

Website: [drive.thinecraft.io](https://drive.thinecraft.io)

DriveCraft is the planned open-source OneDrive alternative for Zorin OS and other Linux systems, Windows, and macOS. It is intended to support large local file catalogs, managed metadata, ShareCraft and Microsoft Graph integration, migration, and organization-controlled offline copies.

> **Status:** Early prototype. A Rust command-line client and a desktop app exist, and the core passes its automated tests against a stand-in server. Both have had a manual trial against a small SharePoint Online test library and is not ready for production data.

- [Getting started](getting-started.html): build it, register the app, and try it on a test library.
- [Scope](scope.html): what DriveCraft is meant to become, and what is still undecided.
