# DriveCraft

Website: [drive.thinecraft.io](https://drive.thinecraft.io)

DriveCraft is the planned open-source OneDrive alternative for Zorin OS and other Linux systems, Windows, and macOS. It is intended to support large local file catalogs, managed metadata, ShareCraft and Microsoft Graph integration, migration, and organization-controlled offline copies.

> **Status:** Placeholder repository. No working implementation is provided or implied.
