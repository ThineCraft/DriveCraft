DriveCraft

Code signing policy

Windows checks who published a program before it runs it. This page says how DriveCraft installers are built and signed, who approves them, and what DriveCraft sends over the network.

Signing

Status: DriveCraft is applying to the SignPath Foundation for free code signing. Until it is accepted, installers are not signed with a code-signing certificate, and Windows warns before running them.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

  • Only installers built by GitHub from this project's public source, by its release workflow, are signed.
  • Every signing request is approved by hand by a project approver.
  • DriveCraft contains only open-source code: its own, published under the MIT License, and open-source libraries.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

DriveCraft talks only to the services its user connects it to:

ServiceWhenPrivacy policy
Microsoft sign-inWhen the user signs in with a work account.Microsoft
Microsoft Graph, SharePoint and OneDrive for workTo list, download and upload the libraries the user chose to synchronize, and to read who may open them.Microsoft, under the user's organisation's agreement with Microsoft
Microsoft Edge WebView2The installer downloads it from Microsoft only if Windows does not already have it.Microsoft
This websiteOnly when the user clicks the link to it in the app.No cookies, no tracking

DriveCraft collects no usage statistics and sends no crash reports.

Changes to this computer

The installer installs DriveCraft for the current user only and needs no administrator rights. DriveCraft adds its synchronized folders to File Explorer, with status icons, and starts with Windows only if the user turns that on. It is removed from Windows' Installed apps, like any other program.

Checking a download

Each installer comes with a SHA-256 checksum, and GitHub signs a record of the repository, commit and workflow that built it. With the GitHub command-line tool, anyone can check it:

gh attestation verify DriveCraft_<version>_x64-setup.exe --repo ThineCraft/DriveCraft
